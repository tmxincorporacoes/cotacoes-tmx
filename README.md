# TMX · Mapa de Cotação

Tela que lê cotações de fornecedores (PDF, Excel, CSV), casa os itens com a ordem de compra e monta o mapa comparativo.

Este repositório contém **só o código da tela**. Não há dados, PDFs, planilhas, chaves nem URLs de backend aqui.

- Os dados ficam numa planilha do Google, acessada por um Web App do Apps Script, que exige um token.
- Na primeira vez, clique em **Conexão** e informe a URL do app da web e o token. Eles ficam só no navegador de quem usa.
- Sem URL e token, a tela funciona apenas em modo de cópia local (dados só no próprio navegador).

Não suba PDFs, planilhas, preços, CNPJs nem chaves neste repositório (ele é público).
